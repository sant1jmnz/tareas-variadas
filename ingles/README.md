## Cómo usarlo

1. Lee el tema de gramática y luego haz el ejercicio que le corresponde.
2. Intenta responder **antes** de abrir "Ver respuestas".
3. Anota cada palabra nueva en `vocabulario/` usando la plantilla.
4. Guarda tus propias tareas en `ejercicios/` con la fecha en el nombre, por ejemplo `2026-11-20-tarea.md`.
