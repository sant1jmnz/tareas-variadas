# Inglés 🇬🇧

Espacio para estudiar inglés.

## Estructura

| Carpeta | Para qué sirve |
|---|---|
| [`vocabulario/`](vocabulario/) | Listas de palabras nuevas con su traducción y un ejemplo |
| [`gramatica/`](gramatica/) | Apuntes de reglas gramaticales (tiempos verbales, etc.) |
| [`ejercicios/`](ejercicios/) | Tareas y ejercicios resueltos |
| [`lecturas/`](lecturas/) | Textos para practicar comprensión lectora |

## Cómo usarlo

1. Anota cada palabra nueva en `vocabulario/` (una lista por tema o por semana).
2. Resume cada tema de gramática en un archivo propio dentro de `gramatica/`.
3. Guarda tus tareas en `ejercicios/` con la fecha en el nombre, por ejemplo `2026-11-20-present-simple.md`.
